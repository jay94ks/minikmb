# Early hardware studies

This directory preserves early candidate symbols, footprints, pin maps and the incomplete MS2130 test board. These are historical studies, not the fabricated STM32H7 board. The MS2130 test PCB is not fully routed and must not be submitted for fabrication as a finished design. Experimental auto-router outputs and private validation journals are excluded.

The actual board uses GL3510-OSY52, not the GL3523 candidate documented here. Manufacturer references and JLCEDA/EasyEDA attribution are in `references/SOURCES.md`. Original KiCad-derived geometry retains its upstream library license and exception.
