# MiniKMB 공통 UI 시트

버전 0.5 · 2026-11-21 · 구현 기준: [theme.rs](../src/theme.rs)

## 참고와 해석

사용자가 제공한 Proxmox Datacenter Manager 스크린샷 두 장에서 다음 특성을
참고했습니다. 색상은 압축된 이미지에서 정확히 추출한 제품 원본 값이 아니라
MiniKMB에 맞춰 새로 정한 근사 팔레트입니다.

- 검정에 가까운 배경 대신 여러 단계의 중성 회색으로 작업 영역을 구분합니다.
- 작은 버튼과 촘촘한 목록을 쓰되 본문·상태·선택의 계층은 명확하게 구분합니다.
- 파란색은 선택, 포커스, 섹션 제목에 제한적으로 사용합니다.
- 얇은 경계선, 작은 모서리, 밑줄 탭과 모노스페이스 출력 영역을 사용합니다.

추가로 제공된 1.0.0 화면에서는 다음 차이를 반영합니다. 탐색 메뉴의 파란
선택과 패널 내부 목록의 회청색 선택을 구별하고, 패널 제목·탭·내용은 얇은
구분선으로 연결합니다. 긴 목록에는 스크롤바 공간을 확보해 마지막 열이나
조작 버튼을 덮지 않게 합니다. 다단 탐색이나 차트는 MiniKMB에 필요한 화면에만
사용하며, 참고 화면의 3열 구성 자체를 공통 레이아웃으로 강제하지 않습니다.

참고 제품의 로고·브랜드 색·사용자 메뉴·브라우저 주소 표시줄·대시보드 구성은
복제하지 않습니다. MiniKMB는 기존 요구대로 **항상 보이는 상단바와 영상 중심
제어 화면**을 유지합니다. 제어 화면에서는 탐색 사이드바를 숨겨 영상 면적을
확보하며, 상단의 채널 목록 버튼으로 돌아갑니다. 하단 도구 모음·입력 잠금·
기능 제한 배지는 추가하지 않습니다.

## 글꼴·간격·크기

크기는 egui 논리 포인트 기준이며 OS 배율에 따라 렌더링합니다.

전역 일시 알림은 우측 하단 floating toast로 표시합니다. 본문·영상 레이아웃을
밀지 않으며 클릭·키보드 포커스를 가로채지 않습니다. 확인 버튼 없이4초 후 또는
화면 이동 시 사라집니다. 입력 완료 미확인·취소·오래된 세션 알림은 진단 로그에만
남기고, 명령 거부처럼 확정된 입력 실패만 toast에 표시합니다.

| 항목 | 기준 |
|---|---|
| 페이지 제목 | 20pt, 보통 굵기, 강조색 |
| 패널/채널 제목 | 16pt, 필요할 때만 굵게 |
| 본문 | 14pt |
| 버튼·탭 | 13pt |
| 보조 정보·UID·로그 | 12pt; UID·코드는 모노스페이스 |
| 기본 단위 / 요소 간격 | 4pt / 8pt |
| 패널 안쪽 여백 | 16pt |
| 입력·버튼 최소 높이 | 30pt |
| 탐색 행·탭 높이 | 32pt |
| 스크롤바 / 최소 손잡이 길이 | 8pt / 24pt; 내용과 별도 공간, 스크롤 가능할 때 표시 |
| 상단바 높이 | 최소48pt; 영상 조작 행을 포함하면 늘어나며 자동 숨김 없음 |
| 탐색 영역 너비 | 196pt |
| 패널·버튼 모서리 | 4pt; 대화상자 6pt |
| 경계 / 활성 포커스 | 1pt / 1.5pt |

본문에는 Noto Sans KR Regular 2.004를 실행 파일에 포함합니다. 코드에는 기본
모노스페이스와 같은 한글 글꼴의 대체 경로를 사용합니다. 시스템 글꼴 설치나
런타임 다운로드 없이 표시하며, 독점 시스템 글꼴을 복사하지 않습니다. 탐색 메뉴는
Lucide 0.577.0의16pt 아이콘과14pt 이름을8pt 간격으로 배치합니다. 아이콘은
전용 글꼴에 격리하고 접근성 이름에는 읽을 수 있는 메뉴 이름만 넣습니다.
출처/해시/라이선스는 [UI 자산 기록](UI-ASSETS.md)에 고정합니다.

## 공통 컴포넌트와 상태

| 컴포넌트 | 함수/설정 | 적용 규칙 |
|---|---|---|
| 전체 테마 | `theme::apply` | 앱 시작 시 한 번 적용; 각 화면의 개별 색상 정의 금지 |
| 패널 | `theme::panel` | 회색 면·얇은 선·16pt 여백; 과한 카드 장식 금지 |
| 제목/설명 | `theme::heading` | 제목 아래 짧은 설명, 불필요한 빈 설명 줄 없음 |
| 탐색/선택 행 | `theme::navigation_icon` / `theme::navigation` | 행 전체에 선택 배경; 키보드 포커스 유지 |
| 패널 내부 목록 | `theme::list_row` | 회청색 선택 배경+왼쪽 강조선; 문서/이미지 목록 등에 재사용 |
| 그룹 제목 | `theme::group_label` | 보조색과 여백으로 묶음 구분 |
| 짧은 수치·단위 | `theme::inline_metric` | 값과 Hz 등의 단위를 한 덩어리로 줄바꿈; 단위만 다음 줄로 남기지 않음 |
| 도구 창 | `theme::tool_window` | 현재 상단바 아래·클라이언트 안에 제목/닫기/크기 조절부 유지; 넘치는 내용은 스크롤로 접근 |
| 탭 | `theme::tab` | 선택 탭의 글자와 2pt 밑줄만 강조 |
| 상태 | `theme::status` | 중립/성공/주의/실패; 점+텍스트 |
| 코드·로그 | `theme::code` | 어두운 입력면, 모노스페이스, 가로 스크롤 |
| 빈 상태 | `theme::empty` | 상태 제목과 다음 조작을 짧게 안내 |
| 입력/버튼/메뉴/체크박스 | egui 전역 style | 기본·호버·누름·비활성 상태에 공통 토큰 적용 |

기본 버튼은 중성 회색, 강조 버튼은 절제된 선택색을 사용합니다.
포커스는 키보드 사용 시에도 보이도록 유지합니다. 파괴 작업은 위치와
명시적인 확인 흐름으로 구분하며, 위험을 줄이기 위해 기능을 숨기지 않습니다.
짧은 로그나 상태 메시지에 키 입력·API 키 원문·파일 내용을 포함하지 않습니다.

## MiniKMB 화면 적용

- 상단바: 현재 채널 이름/UID와 전역 이동·도구. 선택 채널이 없으면 채널 관리.
- 채널 목록: 검색·개수·간결한 패널 행, 이름→UID→타깃 상태 순서.
- 제어 화면: 사이드바 없이 영상 작업면, 상단바 유지, 검은 영상 여백.
- 서버·키: 같은 입력·버튼·보조 텍스트·오류 색상을 사용.
- REST 문서: 왼쪽 선택 목록, 오른쪽 제목/계약/코드, 서버 OFF에서도 접근.
- 이후 디스크/네트워크/시리얼 창: 이 토큰과 공통 컴포넌트를 재사용.
  디스크의 좌측 문맥 기능/우측 목록/+ 메뉴 등 기존 기능 구조는 유지.

## 시각 검증

`--screenshot <절대 PNG 경로> --style-preview`는 공통 컴포넌트 시트를
실제 egui 렌더러로 그린 뒤 종료합니다. USB 검색·HID·서버 시작·키 생성은
하지 않습니다. `--style-preview` 단독으로는 일반 실행을 변경하지 않습니다.
`--screenshot`만 지정하면 실제 채널 목록 화면의 빈 상태를 검증합니다.
`--screenshot <절대 PNG 경로> --style-preview --tty-preview`는 장치 연결 없이
비활성 조작부와 명시적 예시 문구로 터미널 대화상자 배치를 검증합니다.
`--screenshot <절대 PNG 경로> --control-preview`는 채널/영상 연결 없이
고정 상단바·기본OFF 특수 키 옵션·가상 키보드의 제어 화면 배치를 검증합니다.
`--screenshot <절대 PNG 경로> --style-preview --storage-preview` 또는
`--metadata-preview`는 명시적인 UI 예시 데이터로 SD 목록/이름·사용자 값 창을
렌더링합니다. 장치 명령·작업 시작·클립보드 복사는 비활성화합니다.
`--screenshot <절대 PNG 경로> --style-preview --card-format-preview`는 전체 SD
카드 포맷의 파일 시스템 선택·카드 UUID·삭제 확인·취소 불가 안내를 자체 렌더합니다.
같은 회색 패널/입력/강조 토큰을 사용하며 실제 포맷은 시작하지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --folder-preview`는 원본 불변·RO
스냅샷·수동 갱신을 안내하는 폴더 공유 확인 창을 장치 없이 렌더합니다.
`--screenshot <절대 PNG 경로> --style-preview --network-preview`는 NCM 모드·
DHCP 입력·통계·임대 목록의 네트워크 창을 렌더합니다. 실제 NCM/호스트 공유를 켜지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --scan-preview`는 같은 네트워크 창의
포트 스캔 탭·비활성 입력·가상 진행/결과 목록을 렌더하며 프로브를 보내지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --forward-preview`는 같은 네트워크 창의
포워딩 탭·규칙 표/입력·상태를 렌더하며 실제 수신 포트를 열지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --preferences-preview`는 설정 페이지의
가져오기·재불러오기·저장된 채널 표를 예시 데이터로 렌더합니다. 설정 파일을 쓰거나
실제 파일 선택기를 열지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --wake-preview`는 PC 깨우기 창의
MAC·LAN 선택/저장·발신·미지원 안내를 예시 데이터로 렌더합니다. 어댑터를 조회하거나
실제 WOL 패킷을 발신하지 않습니다.
`--screenshot <절대 PNG 경로> --style-preview --logs-preview`와 `--diagnostics-preview`는
로그 필터/보관 정책/표와 진단 상태·카운터/미확인 표현을 예시 데이터로 렌더합니다.
실제 로그를 쓰거나 폴더를 열거나 장치 기능을 켜지 않습니다.

배치 점검에는 `--preview-scale 100|150|200 --preview-size 840x560|1280x820`을
함께 지정할 수 있습니다. 실제 Windows DPI 설정을 바꾸지 않고 egui 배율과
클라이언트 크기를 고정하며 PNG 옆 JSON에 요청/실제 배율·논리/픽셀 크기를 남깁니다.
하드웨어 probe와 결합할 수 없고 새 임시 프로필·비활성 창·입력 무시를 사용합니다.
서버/API 키 화면은 `--style-preview --keys-preview`로 같은 방식으로 확인합니다.

가상 키보드는 모든 기존 키/usage를 보존하며 행 단위를 물리 픽셀에 맞춰 내림합니다.
최소 창에서도 Pause/ScrLk 등이 버튼 패딩 때문에 행 밖으로 밀리지 않도록
키보드 행 안에서만 좌우 패딩3pt를 사용합니다. 긴 채널 제목은 상단 조작 버튼
공간을 남겨 줄이고, 전체 이름/UID는 호버로 확인합니다.

가상 키보드의 보조키 아래에는 사용자 지정 키 선택기와 **조합 전송…**을 둡니다.
기존 앱의94개 선택지(F1~F24·탐색·한영/한자 포함)를 제공하고 선택만으로 전송하지
않습니다. 전송 버튼은 원래 UID/세대에 고정한 확인 창을 열며 확인 후에만 보조키를
한 번 소비합니다. 취소는 선택을 유지합니다. 작은 창에서는 행 단위로 줄바꿈합니다.

이 미리보기는 디자인 QA입니다. 실제 장치 기능·OS DPI 전환·IME·키보드 탐색의
전체 회귀 검증을 대신하지 않습니다. 재현 방법과 결과 범위는
배율·창 배치 점검 (development reference omitted)에 구분합니다.
