## 개발 참고자료

[STM32 프로토콜·메모리맵](../firmware/stm32h7/README.md), [RP2040 master](../master/PROTOCOL.md)·[slave](../slave/kbm-slave/PROTOCOL.md), [네이티브 앱](../kbm-rs/README.md), [Electron 앱](../kbm/README.md)의 상세 기술 자료를 연결합니다. 공개 안내문서와 달리 상세 명세·소스 주석은 원래 작성 언어를 유지하는 공유 개발 참고자료입니다. 앱 안에서도 REST API 문서와 MCP 연동 안내를 볼 수 있습니다.

외부 라이선스와 제조사 데이터시트는 원문을 보존합니다. 한글 고지는 이해를 돕는 설명이며 원래 라이선스 문구를 대체하지 않습니다.
